# Research ledger

Verified against primary sources on **2026-11-05**. These references motivate design choices; EvidenceLab does not claim to reproduce their reported results. Model cards and library APIs change: pin revisions for published experiments.

| Reference | Source | How it informs EvidenceLab | Boundary |
|---|---|---|---|
| Qwen3.5-4B / 0.8B | [4B card](https://huggingface.co/Qwen/Qwen3.5-4B), [0.8B card](https://huggingface.co/Qwen/Qwen3.5-0.8B), [native Transformers integration](https://huggingface.co/docs/transformers/model_doc/qwen3_5) | Explicit local text inference, separate small/primary profiles, adapters | Multimodal weights, text-only application. No local model scores until evaluated. |
| Edge et al., 2024, *From Local to Global: A Graph RAG Approach to Query-Focused Summarization* | [arXiv:2404.16130](https://arxiv.org/abs/2404.16130) | Graph indexes can address corpus-level synthesis; motivates a graph ablation | Current graph mode is concept co-occurrence and score expansion, without LLM entity extraction or community summaries. |
| Asai et al., 2023, *Self-RAG* | [arXiv:2310.11511](https://arxiv.org/abs/2310.11511) | Adaptive retrieval and critique motivate bounded reflection | Reflection here is a deterministic retry. No trained reflection tokens. |
| Ru et al., 2024, *RAGChecker* | [arXiv:2408.08067](https://arxiv.org/abs/2408.08067), [official code](https://github.com/amazon-science/RAGChecker) | Separate retrieval errors from generation and claim-support failures | Source-offset validation is not the RAGChecker claim-entailment metric. No paid judge required. |
| Dettmers et al., 2023, *QLoRA* | [arXiv:2305.14314](https://arxiv.org/abs/2305.14314) | Frozen quantized backbone + trainable low-rank adapters; NF4 and double quantization | CUDA bitsandbytes path is optional. We do not transfer the paper's hardware/memory claims to Qwen3.5. |
| Rafailov et al., 2023, *Direct Preference Optimization* | [arXiv:2305.18290](https://arxiv.org/abs/2305.18290) | Optional chosen/rejected preference recipe | Requires real preference pairs; no pairs fabricated from benchmark gold. |
| Shao et al., 2024, *DeepSeekMath* | [arXiv:2402.03300](https://arxiv.org/abs/2402.03300) | GRPO groups completion rewards relative to a prompt-level baseline | Experimental recipe uses independently labeled classification; not a reproduction of math RL. |
| Zhu et al., 2025, *MultiAgentBench* | [arXiv:2503.01935](https://arxiv.org/abs/2503.01935), [MARBLE](https://github.com/MultiagentBench/MARBLE) | Compare topology and milestone completion, not only final prose | Current workflows are local research scaffolds; no official benchmark compatibility is claimed. |
| Ruan et al., 2025, *Benchmarking LLMs' Swarm Intelligence* (SwarmBench) | [arXiv:2505.04364](https://arxiv.org/abs/2505.04364), [official toolkit](https://github.com/x66ccff/swarmbench) | Distinguishes decentralized coordination from fixed supervisor graphs | Grid-world swarm tasks are not implemented here. |
| Gao et al., 2026, *SwarmBench: Can Large Language Models Act as Agent Swarm Orchestrators?* | [arXiv:2608.30661](https://arxiv.org/abs/2608.30661) | Adds orchestration process quality, efficiency and cost to accuracy | A distinct paper with the same benchmark name; dynamic routing in EvidenceLab is rule based. |
| Wadden et al., 2020, *Fact or Fiction: Verifying Scientific Claims* | [paper](https://arxiv.org/abs/2004.14974), [official data/code](https://github.com/allenai/scifact), [licenses](https://github.com/allenai/scifact/blob/master/LICENSE.md) | Real claims, evidence paper IDs and support/contradiction labels | Packaged subset is dev-only and selected for a runnable demo; retrieval is not verification. |
| Dasigi et al., 2021, *A Dataset of Information-Seeking Questions and Answers Anchored in Research Papers* | [arXiv:2105.03011](https://arxiv.org/abs/2105.03011), [QASPER](https://huggingface.co/datasets/allenai/qasper) | Optional full-paper QA dataset converter | QASPER is not bundled; annotation provenance and answer variants must be retained. |
| EleutherAI Language Model Evaluation Harness | [official repository](https://github.com/EleutherAI/lm-evaluation-harness), [model interface](https://github.com/EleutherAI/lm-evaluation-harness/blob/main/docs/interface.md) | Standardized task scoring for broad model capability evaluation | Harness version pinned separately; local zero-shot settings differ from many published scores. |
| Bandarkar et al., 2023, *Belebele* | [arXiv:2308.16884](https://arxiv.org/abs/2308.16884), [official project](https://github.com/facebookresearch/belebele) | Parallel multilingual reading comprehension | English, Italian, Spanish are a selected subset of languages, not a global language-quality score. |

Additional capabilities are evaluated through official harness task definitions: [GSM8K](https://github.com/openai/grade-school-math), [MATH](https://github.com/hendrycks/math), [MMLU](https://github.com/hendrycks/test), [HellaSwag](https://rowanzellers.com/hellaswag/), [AI2 ARC](https://allenai.org/data/arc). Dataset licenses and access requirements remain with their publishers; these datasets are downloaded only on explicit execution.

Library references: [TRL SFT](https://huggingface.co/docs/trl/sft_trainer), [PEFT](https://huggingface.co/docs/peft/), [Qdrant local mode](https://github.com/qdrant/qdrant-client), [LangGraph graph API](https://docs.langchain.com/oss/python/langgraph/graph-api), [SentenceTransformers](https://www.sbert.net/), [UMAP](https://umap-learn.readthedocs.io/). Repository versions and environment records are authoritative for actual runs.
